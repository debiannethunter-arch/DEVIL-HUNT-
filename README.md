## 📌 Project Overview
**DEVIL-EYE** is a 4-in-1 Open Source Intelligence (OSINT) framework built to consolidate key reconnaissance workflows into a single interface. Designed featuring a custom terminal frontend, the tool queries public web registries and parsing engines to compile details on network infrastructure, communication paths, and web assets.

> [!IMPORTANT]
> **DISCLAIMER:** This tool is developed strictly for educational, security auditing, and white-hat network analysis purposes. The creator is not responsible for any misuse or compliance violations on third-party platforms.

---

## 🛠️ Integrated Modules

The suite features four core scanning capabilities accessible directly through the navigation menu:

*   **[ 1 ] IP Tracker:** Queries public network allocation data to resolve ISP networks, registry assignment coordinates, and geographic timezones for target host interfaces.
*   **[ 2 ] Show Your IP:** Directly interrogates network ingress adapters to reveal your current outbound public IPv4 gateway and routing path parameters.
*   **[ 3 ] Phone Number Tracker:** Parses structural country prefix codes to verify format validity and isolate regional carrier assignments.
*   **[ 4 ] Username Tracker:** Cross-references public target handles against major online directory systems to flag registered active accounts.

## 🚀 Installation & Launch Execution

### Prerequisites
Make sure your system environment has Python 3.x and the `pip` package manager installed.

### Setup Steps
1. Clone the project files or navigate to your target tool directory:
   ```bash
   cd ~/DEVIL-EYE{github-repo}
   ```

2. Install the necessary networking and parsing packages:
   ```bash
   pip3 install requests phonenumbers
   ```

3. Initialize the interface engine:
   ```bash
   python3 DEVIL-HUNT.py
   ```
